# Difference between a personal loan and a home loan

This page is a fictional Harbourline Bank POC example.

The difference between a personal loan and a home loan in this fictional POC is what the money is for and how long it can run. A personal loan is unsecured and capped lower. A home loan is secured by property and can run much longer. Numeric criteria are on the personal and home eligibility pages. The illustrative personal-loan rate is 12.5% per annum. The illustrative home-loan rate is 8.5% per annum.
