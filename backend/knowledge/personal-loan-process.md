# Process to apply for a personal loan

This page is a fictional Harbourline Bank POC example.

The process to apply for a personal loan is a conversation. After consent, the assistant reads the verified profile, asks only for missing information, checks a salary slip, validates the draft, and submits only after explicit confirmation. The customer does not fill in a manual form.
